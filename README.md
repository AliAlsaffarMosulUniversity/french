# Le français en Irak – الصف الأول المتوسط

تطبيق لتعلّم الفرنسية للصف الأول المتوسط (العراق)، مبني على الكتاب المنهجي ودفتر النشاط:
شرح مفصل لكل حصة، كل كلمة بمعناها ونطقها (طبيعي وبطيء)، حوارات مع تمثيل الأدوار، تمارين الكتاب، اختبارات وألعاب.

- يعمل على الهاتف والآيباد والحاسوب، ويُثبَّت كتطبيق.
- وضع ليلي ونهاري.
